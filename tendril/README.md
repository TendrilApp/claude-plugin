# Tendril — Claude Code plugin

Installs the Tendril MCP server and the tendril skill together.

Requires Node ≥20 on this machine (the MCP server runs from the
`@tendrilapp/cli` npm package via npx) and Google Chrome for
verification. Run the `tendril doctor` CLI command for a readiness
report.

Verification (`tendril verify`) is local, account-less, and
network-less — always.
